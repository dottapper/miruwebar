# Vercel Blob の容量と課金の単位

## データベースではない

公開先は **Vercel Blob Storage**（オブジェクトストレージ）です。Postgres 等の「プロジェクト用 DB」とは別物です。

## 容量は「1プロジェクトあたり」ではない

| 単位 | 内容 |
|------|------|
| **Vercel アカウント（チーム）** | そのアカウントに紐づく **すべての Blob ストアの合計** が課金・無料枠の対象 |
| **Blob ストア** | 1つのストア内に、全 AR プロジェクトの `projects/{id}/releases/...` が同居 |
| **miru-WebAR のプロジェクト ID** | パスのフォルダ名。Vercel 側で「1プロジェクト = 1GB」のような制限は **ない** |

参考（2025年時点の公式目安）:

- **Hobby**: ストレージ **1 GB/月**（全ストア合計）、超過すると Blob がブロック（追加購入不可）
- **Pro**: **5 GB/月** 込み、超過分は **$0.023/GB/月** など従量
- **操作**: 簡易 10,000/月、高度（アップロード・一覧）2,000/月（Hobby）

詳細: https://vercel.com/docs/vercel-blob/usage-and-pricing

## 再公開と削除

- 再公開のたびに `releases/{releaseId}/` が **追加** される（上書きしない）
- QR モーダル「公開リリース」タブから **古いリリースを削除** 可能（`/api/blob-releases`）
- 削除した URL の QR は **404** になる

## 環境変数

- `BLOB_READ_WRITE_TOKEN` — 公開・削除 API に必須（本番）
- `BLOB_QUOTA_TIER` — `hobby`（既定）または `pro`。管理画面のプログレスバー表示用
